# Security

Found a way to read someone's data, act as someone else, or get the skill to run something it shouldn't? Please email admin@psycheai.io with the steps to reproduce it, and give us a reasonable time to fix it before telling anyone else. We reply within a few days.

What this code keeps, and how, is in README.md ("Nothing readable kept", "Signed skill updates", "What leaves the workspace"). The skill's releases are signed with a key that is never in this repo or on the server.
